Northern Regional Soybean Uniform Trials (NUST)

Query phenotypic values, strain evaluations, and common test comparisons from the USDA-ARS Northern Uniform Soybean Trials database.

General Phenotype Search Tool

Retrieve some or all phenotypic values for all or some strains from a given year(s) and test(s). You can limit your query to a given location, strain, or phenotype.

Hold Ctrl/Cmd to select multiple
'ALL' selects all tests
'ALL' selects all locations
'ALL' selects all strains
'ALL' selects all phenotypes
Tips:
  • The dropdown lists filter down automatically as you make selections.
  • To select multiple entries: hold Ctrl (Windows/Linux) or Cmd (Mac) while clicking, or hold Shift to select a range.
  • The "Retrieve Results" button is enabled once you have made selections in all five columns.
